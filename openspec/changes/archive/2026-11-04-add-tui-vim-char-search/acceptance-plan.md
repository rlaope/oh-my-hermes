## Required Fixture and Falsification Detail
- All twelve d/c/y x f/F/t/T subtests use fresh `xabcQabcx`, caret 4; selected strings: fx `Qabcx`, tx `Qabc`, Fx `xabc`, Tx `abc`. d results/carets: `xabc`/3, `xabcx`/4, `Qabcx`/0, `xQabcx`/1. c results equal d strings but INSERT carets 4,4,0,1 (forward fx insertion may be at buffer end); y text unchanged, NORMAL carets 4,4,0,1. Registers are characterwise exact selected strings for all nonempty spans.
- Positive counts include 2fb, d2fb, 2dfb, 2d3fb; backward and till variants exercise nth occurrence, count cap and literal 0 target. Too few matches must preserve complete pre-command state after pending drops. ;/, with no memory are tested both standalone and with c and counts.
- Miss/cancel tests snapshot caret, text, normal, register including metadata, pastes, images, _undo, _redo, last successful search; compare equality except pending. Prior memory is established before a failed counted explicit search and replayed to show it was not replaced. Check stale operator/count/leader cannot affect next h/x/i command.
- Newline fixtures place a matching target only across NEWLINE in both directions; include empty buffer, empty middle line, first/last line and same logical line rendered at different widths. Wrap width must not alter result. Search target exactly at buffer edge must succeed without crossing.
- Target input fixtures include digit, ;, comma, i/a/g/r/d, space, punctuation, normalized/decomposed grapheme, a multi-codepoint grapheme, invalid multi-grapheme CHAR, tab, control text, NEWLINE and reserved token. Chips/image labels containing the requested char do not match. Operators traverse chips/images whole and put/undo/redo restores their metadata.
- Exercise all four search kinds under Escape and invalid events: BACKSPACE, DELETE, Enter, arrows and modified CHAR. Paste and shared Ctrl undo/redo assert their existing effects only after search pending clears. Prefix cancellation must never become h/x or a leader follower.
- Repeat tests cover both stored directions, temporary comma inversion followed by ;, successful adjacent explicit till, ; progression, 2; and counted d/c/y; failed 3; must not partially move. Mirror with `XcXbXa` at caret 5: TX lands 5, ; reaches 3, ; reaches 1, comma reaches 3; counted 2; from the fresh explicit-TX state reaches 1. On forward `aXbXcX` at 0 after tX, d2; uses final match m=5 and span [0,5), selecting `aXbXc` and leaving `X`. Never initialize NORMAL beyond the last atom. Memory survives ordinary edit/undo/history/INSERT and is erased by set_vim, successful submit and _clear; independent instances cannot share it.
- Full operator effect tests include normal d then u/Ctrl-redo, c followed by typing/Escape then one u/Ctrl-redo, y then p/P, no-op and y preserving undo stacks, and preexisting nonempty register not overwritten by successful empty dT/yT.
