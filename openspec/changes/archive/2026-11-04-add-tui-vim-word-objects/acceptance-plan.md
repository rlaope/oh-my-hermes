## Falsification Coverage Details
- Range subcases: first/interior/last atom, single word, punctuation-only token, mixed tabs/spaces, leading/trailing/all blanks, NBSP, newline and empty line. On `one  two`, final-word daw takes the entire leading run. On `one  two  three`, a caret in blanks takes `  two`, not the next trailing blanks.
- Count subcases: 1, pre-operator, post-operator, product, zero motion behavior unchanged, count cap 9999, excessive count truncation, `di2` invalid and consumed, `2diw` removing first word+blanks, `d2aw` spanning two words. Across lines: a huge count on first line leaves NEWLINE and subsequent lines byte-for-byte intact.
- Pending subcases: d/c/y × i/a × Escape, unknown follower, digit follower, non-character key, set_vim off/on, Paste and Ctrl undo/redo. Compare existing cancelling-event behavior, then verify next normal command does not inherit object state. Insert mode after c must not leave an operator/prefix/count.
- Operator subcases: the full d/c/y × iw/aw cross product. Assert text/caret/mode, pending false, linewise false, register exact text/pastes/images, and undo depth for each. `ciw` then replacement typing then Escape/u must restore the original whole draft in one undo; redo restores the change under existing rules. `yiw`/`yaw` create no undo entry. Empty d/y preserve a preseeded register; empty c enters INSERT with no text undo entry until typing.
- Atomic subcases: NFC and multi-codepoint graphemes, long Paste-created chips with spaces in labels, image atoms alone and adjacent to text; no boundary lands inside an atom. d/c capture full metadata before removal; y preserves draft metadata; put restores metadata using existing machinery.
- Compatibility subcases: Vim INSERT, vim=False, masked=True; standalone i/a; original dw/cw/yw/dd/cc/yy; g/r incomplete prefixes; Alt+b/f; leader before object-looking followers and operator+space; application Escape cancellation is not a global clear/interrupt/rewind. Existing leader suite is mandatory, not just new unit tests.
